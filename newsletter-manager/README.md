# ניהול הניוזלטרים · הורה ומיוחד

ניהול הניוזלטרים **ישירות באתר החי**, בשתי דרכים שהן אותה מערכת בדיוק:

1. **דף ניהול באתר:** `ho-me.org.il/admin` — נפתח בדפדפן מכל מחשב, בלי להתקין כלום.
2. **אפליקציית דסקטופ** (Windows) — אותו ממשק, למי שנוח לו יותר.

ההתחברות בשתיהן: **אימייל וסיסמה**. בלי טוקנים, בלי GitHub, בלי שום דבר טכני למשתמש.

## איך זה עובד (כל התמונה בפסקה אחת)

האתר הוא קבצים במאגר GitHub ש-Vercel מציג. בתוך אותו פרויקט Vercel יושבת פונקציית שרת אחת (`api/newsletter-admin.js`) שמחזיקה את מפתח ה-GitHub, בודקת אימייל+סיסמה מול רשימת המשתמשים שמוגדרת בהגדרות Vercel, ומבצעת את השינוי במאגר. Vercel מזהה את השינוי ופורס את האתר המעודכן תוך דקה-שתיים. **אין אף מערכת נוספת**, הכול בפרויקט אחד.

## הקמה חד-פעמית (שני משתני סביבה ב-Vercel)

בלוח הבקרה של Vercel → הפרויקט של האתר → Settings → Environment Variables:

1. **`NEWSLETTER_USERS`** — רשימת המשתמשים המורשים, בפורמט `אימייל:סיסמה` מופרדים בפסיק:
   `o@ho-me.org.il:סיסמה1,zvi@ho-me.org.il:סיסמה2`
2. **`GITHUB_TOKEN`** — מפתח GitHub (Fine-grained token של חשבון האתר, עם Contents: Read and write על מאגר האתר בלבד).

אחרי הגדרה או שינוי של משתנים: Deployments → ⋯ → Redeploy (או כל push). זהו.

**ניהול משתמשים ביום-יום:** הוספה/הסרה/החלפת סיסמה = עריכת השורה `NEWSLETTER_USERS` ב-Vercel ו-Redeploy. מי שהוסר מאבד גישה מיד.

## שימוש בדף הניהול באתר

נכנסים ל-`ho-me.org.il/admin`, מתחברים, וזהו. תמיד מעודכן, עובד מכל מחשב ודפדפן.

## אפליקציית הדסקטופ (רשות)

- התקנה: מעתיקים את `dist\NewsletterManager-win32-x64.zip` (כ-150MB), מחלצים, מריצים `NewsletterManager.exe` (אם SmartScreen מתריע: "מידע נוסף" → "הפעל בכל זאת"). לא צריך Node או כל התקנה אחרת.
- מתחברים עם אותו אימייל וסיסמה. ההתחברות נשמרת מוצפנת במחשב.
- יש בה גם "כניסה לצפייה בלבד" בלי התחברות.

## מה אפשר לעשות (בשתי הדרכים)

- **הוספת גיליון** מקובץ HTML (גרסת אתר). סקריפט נגישות ואנליטיקה מתווספים אוטומטית אם חסרים.
- **סדר** בחצים: הראשון הוא "הגיליון האחרון" באתר וממנו מתעדכן `latest.html`.
- **עריכה** של תאריך/כותרת/תיאור (שינוי תאריך משנה את שם הקובץ באתר).
- **מחיקה** לצמיתות (עם סימון, אישור, ואפשרות חרטה עד השמירה). חייב להישאר גיליון אחד לפחות.
- **חיפוש** לפי כותרת, תיאור, מספר, תאריך ותוכן הגיליון.
- **גיליון עתידי:** נשמר בהמתנה (לא באתר), וביום היעד מוצגת התראה ומפרסמים בלחיצה. את המייל מתזמנים ברב מסר.
- **שמירה** מפרסמת הכול בפעולה אחת; אם מישהו אחר שינה בינתיים, השמירה נעצרת (אין דריסה).

## אבטחה

- מפתח ה-GitHub והסיסמאות נמצאים רק בהגדרות Vercel (ששם ממילא נשלט האתר). אצל המשתמשים אין שום סוד מלבד פרטי ההתחברות שלהם (בדסקטופ נשמרים מוצפנים ב-Windows DPAPI).
- כל שינוי נרשם כ-commit במאגר **עם האימייל של מי שביצע**, עם היסטוריה מלאה ואפשרות שחזור.
- המערכת לא שולחת מיילים. הדיוור נשלח ברב מסר בלבד (ה-API של רב מסר תומך בניהול נמענים אך לא בשליחת קמפיינים; שיגור ותזמון בממשק שלהם).

## למפתחים

- דסקטופ מקוד מקור: `npm install` ואז `npm start`.
- אחרי שינוי בממשק (renderer.js/styles.css): `npm run build-admin` מעדכן את דף הווב `admin/`, ו-`npm run build` בונה את חבילת הדסקטופ (לכווץ את `dist\NewsletterManager-win32-x64` ל-ZIP).
- בדיקות: `npm run smoke` (מריץ את האפליקציה בפועל), `npm run test-api` (בודק את פונקציית השרת מקומית).
- השרת: `api/newsletter-admin.js` במאגר האתר. דף הווב: `admin/` (נבנה אוטומטית, לא לערוך ידנית).
- הערה ל-VS Code: אם Electron לא נפתח מהטרמינל, להריץ קודם `Remove-Item Env:ELECTRON_RUN_AS_NODE`.
